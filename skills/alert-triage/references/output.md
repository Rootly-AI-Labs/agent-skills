# Triage brief

- Alert identity, recorded state, measured metric, service, and observation time.
- First event and related group events, with any timeline/coverage limitations.
- Attached incident as recorded, none if verified, or unknown.
- One recommendation: open a new incident, attach, wait/recheck, or dismiss.
- Evidence supporting that choice, unresolved impact, and misleading/stale signals.
- What evidence would change the choice; for waiting, the responsible human and
  explicit escalation trigger/recheck condition.
- Proposed cross-link or next check when useful; state that no action was executed.

Do not equate a tool's grouping with a demonstrated shared problem. If deciding
between risky dismissal and an unnecessary incident, favor surfacing the possible
problem and explain the uncertainty. Apply known customer policy explicitly.
